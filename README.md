# TR2 - Translation App

A SwiftUI-based iOS app that allows users to translate text. Users can input text manually or use the camera to capture text, and then translate it into their desired language.
## Features
- Translate text between multiple languages.
- Capture text using the device camera.
- Translate captured text with a single button press.
- Keeps history of translations.
